# Immersive Folder

[English](README.md) · [简体中文](README.zh-CN.md) · 繁體中文 · [日本語](README.ja.md) · [한국어](README.ko.md)

一個 Obsidian 外掛。當你在某個資料夾裡工作時，可以一鍵只留下這個資料夾裡的筆記，
其他內容暫時被遮住。你也可以直接拖曳資料夾調整順序，不必再靠 `01_收件匣`、
`02_專案` 這樣的命名去湊出想要的次序。

![檔案列表中 Clippings 資料夾保持可讀，其餘每一列都變成骨架條](docs/screenshot.png)

要沉浸在哪個資料夾，是依你目前開啟的檔案自動判斷的 —— 不用手動選。

## 為什麼要有它

- **專注。** 兩千篇筆記的儲存庫，不再和你手邊真正在處理的那十幾篇搶注意力。
- **會議投影。** 開會講某個專案時把畫面投出去，滿屋子人看到的只有你要講的那個
  資料夾，而不是隔壁專案、另一個客戶、以及你自己私下記的那些東西的名稱。
- **螢幕錄影。** 只呈現影片要講的那個資料夾，側邊欄其餘部分保持不可讀，不用為了
  錄一段影片先去重新整理你的儲存庫。

## 怎麼用

- **檔案列表頂端的按鈕**，點一下開關。遮擋開啟時它會染上你的主題強調色，一眼
  就能看出目前狀態。
- **命令面板裡的 `Immersive Folder: Toggle immersive folder`**，作用相同，可以
  綁快速鍵 —— 如果你經常在錄影前後開關，值得綁一個。

開關狀態會在重新啟動後保留。

### 調整資料夾順序

點擊檔案列表頂端的上下箭頭按鈕，所有資料夾會浮起來，每個前面多出一個握把，這時
就能拖曳它們調整順序。改動隨手儲存，再點一次按鈕離開。

![開啟調整資料夾順序模式後，拖曳一個資料夾就能改變它在同層資料夾中的位置](docs/arrange.gif)

只能在同層之間調整：一個資料夾只能在自己的同層資料夾之間換位置，不能拖去別的
層級。這樣調順序和搬動位置就不會混在一起。

也只有資料夾參與調整。檔案的順序仍然由 Obsidian 的排序選單決定，你選按檔名還是
按修改時間，照舊生效。

這是本外掛獨有的一個模式，進去只做一件事：調資料夾順序。離開之後，Obsidian 原生的
拖曳照常可用，把檔案或資料夾搬到別的位置一點沒變。兩個功能各管各的，互不干擾。

外掛只記錄順序本身，不重新命名、不搬動任何檔案，也不往你的儲存庫裡寫別的東西。

### 設定項目

**Language（語言）** —— 介面預設跟隨 Obsidian 自己的語言設定。外掛自帶英文和
简体中文，也可以在這裡手動指定。切換即時生效，命令名稱也會跟著變。

**Toolbar buttons（工具列按鈕）** —— 本外掛的兩個按鈕裡，哪些留在檔案列表頂端。
兩個按鈕各自都能看出對應模式開沒開，所以預設都擺在明面上；如果你只用其中一個
功能，可以把另一個藏起來。藏起來的那個，命令面板裡照樣能用；藏了東西之後，設定頁
會多出一列，點一下直接帶你去快速鍵頁面。

**Keep the active file in view（讓目前檔案始終可見）** —— 每次切換筆記時，捲動
檔案列表到那篇筆記，並展開必要的層級把它露出來。沒有這個的話，切到一篇所在資料夾
恰好在視野之外的筆記，你會看到滿螢幕骨架條、別的什麼都沒有。預設開啟。

**Collapse every other folder（收合其他所有資料夾）** —— 每次切換時，把目前資料夾
以外的所有資料夾都收合起來。需要捲動的內容更少，也讓骨架條不再洩漏其他資料夾裡
裝了多少東西。離開沉浸模式時，原先展開的資料夾會照原樣還原。預設開啟。

## 它做不到什麼

**這是視覺遮擋，不是加密。** 那些名稱仍然在頁面裡，任何人打開開發者工具都能讀到。
它是為鏡頭、投影機和你旁邊那個人準備的，不是為了防住一個已經能操作你電腦的人。

遮擋也只作用於檔案列表：分頁標題、筆記自己的麵包屑、搜尋結果和快速切換器都不受
影響，想按名稱搜尋，先把遮擋關掉。另外，如果你關掉「Collapse every other folder」，
骨架條仍然會露出每個資料夾裡有多少個檔案、樹有多深。

## 安裝

在 Obsidian 裡打開 設定 → 第三方外掛 → 瀏覽，搜尋 **Immersive Folder** 安裝即可，
也可以直接打開[社群外掛頁面](https://community.obsidian.md/plugins/immersive-folder)。

需要 **Obsidian 1.13 或更高版本**。行動裝置上各項功能同樣正常，可以放心使用。

也可以手動安裝：從[最新
release](https://github.com/iBlinkQ/immersive-folder/releases/latest) 下載
`main.js`、`manifest.json` 和 `styles.css`，放進
`你的儲存庫/.obsidian/plugins/immersive-folder/`，然後在 設定 → 第三方外掛 裡啟用。
（`main.js` 是建置產物，不保存在儲存庫裡 —— 它只存在於 release 中，或者你自己跑
`npm run build` 之後。）

有問題或建議，歡迎提
[Issue](https://github.com/iBlinkQ/immersive-folder/issues)。

## 開發

```bash
npm install
npm run dev     # 監看建置
npm run build   # 型別檢查並建置 main.js
npm run lint    # 社群外掛審核所用的那套規則
npm run sync    # 建置後複製進 sync.mjs 裡列出的儲存庫
```

`npm run lint` 必須在儲存庫根目錄跑：規則會從工作目錄讀 `manifest.json`。
