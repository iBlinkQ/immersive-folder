# Immersive Folder

[English](README.md) · [简体中文](README.zh-CN.md) · 繁體中文 · [日本語](README.ja.md) · [한국어](README.ko.md)

一個 Obsidian 外掛。當你在某個資料夾裡工作時，可以一鍵只留下這個資料夾裡的筆記，
其他內容全部先被遮住，直到你自己切回來。以及你可以直接拖曳資料夾調整順序，不必再
靠 `01_收件匣`、`02_專案` 這樣的命名去湊出想要的次序。

![檔案列表中 Clippings 資料夾保持可讀，其餘每一列都變成骨架條](docs/screenshot.png)

要沉浸在哪個資料夾，是依你目前開啟的檔案自動判斷的 —— 不用手動選，也不用記得在
換地方時關掉。在別處開啟一篇筆記，骨架條就跟著你過去。什麼都沒開的時候，沒有可以
沉浸進去的資料夾，按鈕會變暗並提示你先開一篇筆記，而不是存下一個它畫不出來的
模式。

保持可讀的只有這個資料夾和它裝著的東西。它**上層**的那些資料夾同樣會被蓋上骨架
條：最上層的名稱往往是畫面上最能說明問題的那一個，把這條路徑留著可讀，等於把遮擋
本來要蓋住的東西原樣交了出去。縮排沒有被動過，所以你依然看得出自己在哪一層。

自訂圖示（來自 [Iconize](https://github.com/FlorianWoelki/obsidian-iconize)）
會變成佔位方塊而不是消失，這樣每一列的形狀都還在，被遮住的列表讀起來仍然像個
列表。

你還可以**手動排列資料夾**：開啟排列模式，拖曳資料夾來決定它們的先後。檔案不參與，
它們始終待在排序選單給的位置上。除了順序本身，不會往磁碟上寫任何東西 —— 檔案一個
都不會被搬動，平常的拖曳也原樣保留。

## 為什麼要有它

- **專注。** 兩千篇筆記的儲存庫，不再和你手邊真正在處理的那十幾篇搶注意力。
- **會議投影。** 開會講某個專案時把畫面投出去，滿屋子人看到的只有你要講的那個
  資料夾，而不是隔壁專案、另一個客戶、或是你自己私下記的那些東西的名稱。投影是
  即時的，沒有剪掉重來的機會。
- **螢幕錄影。** 只展示影片要講的那個資料夾，側邊欄其餘部分保持不可讀，不必為了
  錄一段影片先去重新整理你的儲存庫。

## 怎麼用

- **檔案列表頂端的按鈕**，按一下開關。遮擋開啟時它會染上你的強調色，一眼就能看出
  目前狀態。
- **命令面板裡的 `Immersive Folder: Toggle immersive folder`**，作用相同，可以綁
  快速鍵 —— 如果你常在錄影前後開開關關，值得綁一個。

開關狀態會在重新啟動後保留。

### 手動排列資料夾

檔案列表頂端那個**上下箭頭按鈕**開啟資料夾排列模式。每個資料夾都會長出握把並輕輕
浮動 —— 這是列表在告訴你它現在可以重排了。上下拖曳一個資料夾決定它排在同層資料夾
之間的哪個位置，再按一次按鈕離開。

![開啟資料夾排列模式：摺疊箭頭變成握把，下方的檔案全程保持變暗且沒有握把；每拖曳一個資料夾都會顯示它將落在哪裡](docs/arrange.gif)

**只有資料夾參與。** 檔案不會長出握把、不會浮動，模式開著時還會變暗 —— 它們始終
待在 Obsidian 排序選單給的位置上，所以在檔名和日期之間切換照樣是原本的效果。
外掛負責這棵樹的骨架，排序選單負責骨架裡的每一列。

**按住某個資料夾時，只有接得住它的那些資料夾繼續浮動**，其他層級的會變暗、停下。
調順序永遠是同層之間的事，這樣你能一眼看見，而不必去記。一條線會顯示它將落在哪裡。

改動是隨手儲存的，按鈕只管進出。

某個資料夾第一次被拖過之後，它裡面子資料夾的順序就固定下來。其餘資料夾仍照你在
Obsidian 裡選的方式排序；一個你從沒排過的儲存庫，什麼都不會存。之後新建的資料夾
會先排在最後，直到你把它拖走。

模式開著時整棵樹是靜止的：按一列不會開啟筆記，資料夾也不會摺疊，握把就坐在原本
摺疊箭頭的位置。要展開什麼，進模式之前先展開。

**平常的拖曳完全沒變。** 關掉這個模式，把筆記拖進另一個資料夾和以前一模一樣 ——
那是 Obsidian 自己的功能，本外掛根本不監聽。把兩件事在時間上分開，才讓每一次拖曳
都不含糊：在畫面上，「排到那個資料夾下面」和「放進那個資料夾裡」是同一個像素。

**沉浸模式和排列模式輪流使用。** 遮擋蓋住的正是你要用來排序的那些名稱，所以在一個
開著的時候去開另一個，它會告訴你先關掉誰，而不是悄悄替你關掉。正在等待的那個按鈕
會變暗，滑鼠停上去會說明要先離開哪一個。

### 設定項

**Language（語言）** —— 介面預設跟隨 Obsidian 自己的語言設定。外掛內建英文和
简体中文，也可以在這裡手動指定，覆蓋自動比對的結果。切換即時生效，命令名稱也會
跟著變。

**Toolbar buttons（工具列按鈕）** —— 本外掛的兩個按鈕裡，哪些留在檔案列表頂端。
它們都是能看出模式開沒開的開關，所以預設都擺在明面上；如果你只用其中一個功能，
可以把另一個藏起來。藏起來的那個，命令面板裡照樣能用；藏了東西之後，設定頁會多出
一行，按一下直接帶你去快速鍵設定頁。

**Keep the active file in view（讓目前檔案保持可見）** —— 每次切換筆記時，捲動
檔案列表到那篇筆記，並展開必要的層級把它露出來。沒有這個的話，切到一篇所在資料夾
剛好在視野之外的筆記，你會看到滿螢幕骨架條、其他什麼都沒有。預設開啟。

**Collapse every other folder（收起其他所有資料夾）** —— 每次切換時，把目前資料夾
以外的所有資料夾都收起來。要捲動的內容更少，也讓骨架條不再洩漏其他資料夾裡裝了
多少檔案。離開沉浸模式時，原先展開的資料夾會照原樣還原。預設開啟。

### 改變它的外觀

外掛畫的每樣東西都取自 CSS 變數，寫個 snippet 就能讓它貼合你的佈景主題：

```css
body {
  /* 骨架條 */
  --immersive-folder-bar: var(--text-faint);
  --immersive-folder-bar-opacity: 0.5;

  /* 排列模式：落點線、你按住的那一列、握把，以及其他層級變暗的程度 */
  --immersive-folder-drop-line: var(--color-accent);
  --immersive-folder-drag-bg: var(--background-modifier-active-hover);
  --immersive-folder-handle: var(--text-muted);
  --immersive-folder-dim: 0.32;
}
```

落點線跟隨你在「外觀 → 強調色」裡選的那個顏色，所以不必特別設定，它自己就會跟上
你目前的佈景主題。

## 它做不到什麼

**這是視覺遮擋，不是加密。** 那些名稱仍然在頁面裡 —— 任何人打開開發者工具都讀得
到。它是為了鏡頭、投影機和你旁邊那張桌子而做的，不是為了防住一個已經能操作你電腦
的人。

如果關掉 **Collapse every other folder**，骨架條仍然會洩漏每個資料夾裡**有多少個**
檔案，以及**這棵樹有多深** —— 因為每一列都原樣留在那裡。保持這個選項開啟就能把
這些一併摺疊掉，剩下的只是每個非目前資料夾一根條。如果你希望那些列乾脆消失，那麼
像 [Explorer Focus](https://github.com/davidvkimball/obsidian-explorer-focus)
這類隱藏式外掛會直接把它們移除掉。

遮擋只作用於檔案列表。分頁標題、筆記自己的麵包屑、搜尋結果和快速切換器都不受影響
—— 包括檔案列表自帶的搜尋篩選框開著時，搜尋結果和其他內容一樣會被蓋成骨架條。
想按名稱搜尋，先把遮擋關掉。

## 實作原理

列是靠 `data-path` 屬性比對、打上一個 class，再由一張靜態樣式表接手。這麼做有兩個
原因：檔案列表是虛擬捲動的，一列隨時可能被建立出來，必須一出現就已經帶好樣式；
以及，你所在的資料夾即使處於摺疊狀態、目前檔案那一列根本不在文件裡，它的名稱也
依然正常顯示。

如果沒有開啟任何檔案，樣式表會被清空，而不是繼續遮住一切 —— 所以你永遠不會被困在
一整欄讀不出名稱的骨架條裡。

摺疊和捲動走的是檔案列表自己的列對應表，屬於內部 API：每一處使用都做了防禦性檢查，
所以即便將來 Obsidian 改了名字，也只是這兩個選項失效，遮擋本身照常運作。摺疊只在
目前檔案真的改變時執行，而不是每次重繪都跑，否則你每挪動一次面板它都會和你搶。

自訂順序是蓋在 Obsidian 自身排序之上的一次重新洗牌，而不是取代它。外掛在檔案列表
的原型上改寫了 `getSortedFolderItems`，沒有順序記錄的資料夾會被原樣交還 —— 所以
除了你手動排過的那些子資料夾，排序選單仍然決定一切。被挪動的只有子資料夾那幾列，
而且是在它們本來佔據的索引之間挪，所以每個檔案都還在 Obsidian 放的位置上。順序
按資料夾存成一串子資料夾名稱，且只有你真的拖過的資料夾才會被記錄。

讓「排列順序」和「搬動檔案」互不打架的，正是排列模式。模式關著時，這裡根本不監聽
任何拖曳；模式開著時，檔案列表上的每一個拖曳事件都在捕獲階段被接下，早於 Obsidian
自己的處理器 —— 這不是為了整潔，而是全部的安全性所在：放著不管的話，Obsidian 會
展開指標停留的資料夾，並把檔案搬進它最後看到的那個資料夾裡，包括那些根本沒畫出
落點線的位置，於是這次搬動到來時，畫面上沒有任何東西預告過它。列本身的
`draggable` 來自 Obsidian，所以這裡不需要自己發起拖曳。

那處原型改寫以及隨後的重繪用的都是內部 API，使用前都做了檢查，卸載時會還原；如果
將來的 Obsidian 挪走了它們，排序功能會自行關閉，其餘部分照常運作。

## 安裝

還沒有上架社群外掛列表。從 [最新
release](https://github.com/iBlinkQ/immersive-folder/releases/latest) 下載
`main.js`、`manifest.json` 和 `styles.css`，放進
`你的儲存庫/.obsidian/plugins/immersive-folder/`，然後在 設定 → 第三方外掛 裡啟用。

（`main.js` 是建置產物，不保存在儲存庫裡 —— 它只存在於 release 中，或者你自己跑
`npm run build` 之後。）

## 開發

```bash
npm install
npm run dev     # 監看建置
npm run build   # 型別檢查並建置 main.js
npm run lint    # 社群外掛審核所用的那套規則
npm run sync    # 建置後複製進 sync.mjs 裡列出的儲存庫
```

`npm run lint` 必須在儲存庫根目錄跑：規則會從工作目錄讀 `manifest.json`。
