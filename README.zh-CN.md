# Immersive Folder

[English](README.md) · 简体中文 · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一个 Obsidian 插件。你在某个文件夹里工作时，可以一键只专注于这个文件夹中的笔记，
其他内容被暂时遮住。你也可以直接拖动文件夹调整顺序，不必再靠 `01_收件箱`、
`02_项目` 这样的命名去凑出想要的次序。

![文件列表中 Clippings 文件夹保持可读，其余每一行都变成骨架条](docs/screenshot.png)

聚焦哪个文件夹是根据你当前打开的文件自动判断的 —— 不用手动选。

## 为什么要有它

- **专注。** 两千篇笔记的库，不再和你手头真正在处理的那十几篇抢注意力。
- **会上投屏。** 开会讲某个项目时把屏幕投出去，满屋子人看到的只有你要讲的那个
  文件夹，而不是隔壁项目、另一个客户、以及你自己私下记的那些东西的名字。
- **录屏分享。** 只展示视频要讲的那个文件夹，侧边栏其余部分保持不可读，不用为了
  录一段视频先去重新整理你的库。

## 怎么用

- **文件列表顶部的按钮**，点一下开关。遮挡开启时它会染上你的主题强调色，一眼
  就能看出当前状态。
- **命令面板里的 `Immersive Folder: Toggle immersive folder`**，同样的作用，可以
  绑快捷键 —— 如果你经常在录屏前后开关，值得绑一个。

开关状态会在重启后保留。

### 调整文件夹顺序

点击文件列表顶部的上下箭头按钮，所有文件夹会浮起来，每个前面多出一个手柄，这时
就能拖动它们调整顺序。改动随手保存，再点一次按钮退出。

![打开调整文件夹顺序模式后，拖动一个文件夹就能改变它在同级文件夹中的位置](docs/arrange.gif)

只能在同级之间调整：一个文件夹只能在自己的兄弟文件夹之间换位置，不能拖去别的
层级。这样调顺序和挪动位置就不会混在一起。

也只有文件夹参与调整。文件的顺序仍然由 Obsidian 的排序菜单决定，你选按文件名还是
按修改时间，照旧生效。

这是本插件独有的一个模式，进去只做一件事：调文件夹顺序。退出之后，Obsidian 原生的
拖拽照常可用，把文件或文件夹挪到别的位置一点没变。两个功能各管各的，互不干扰。

插件只记录顺序本身，不重命名、不移动任何文件，也不往你的库里写别的东西。

### 设置项

**语言（Language）** —— 界面默认跟随 Obsidian 自己的语言设置。插件自带英文和
简体中文，也可以在这里手动指定。切换即时生效，命令名也会跟着变。

**工具栏按钮（Toolbar buttons）** —— 本插件的两个按钮里，哪些留在文件列表顶部。
两个按钮各自都能看出对应模式开没开，所以默认都摆在明面上；如果你只用其中一个
功能，可以把另一个藏起来。藏起来的那个，命令面板里照样能用；藏了东西之后，设置页
会多出一行，点一下直接带你去快捷键页面。

**让当前文件始终可见（Keep the active file in view）** —— 每次切换笔记时，滚动
文件列表到那篇笔记，并展开必要的层级把它露出来。没有这个的话，切到一篇所在文件夹
恰好在视野之外的笔记，你会看到满屏骨架条、别的什么都没有。默认开启。

**收起其他所有文件夹（Collapse every other folder）** —— 每次切换时，把除当前
文件夹之外的所有文件夹都收起来。需要滚动的内容更少，也让骨架条不再暴露其他文件夹
里装了多少东西。退出沉浸模式时，原先展开的文件夹会照原样恢复。默认开启。

## 它做不到什么

**这是视觉遮挡，不是加密。** 那些名字仍然在页面里，任何人打开开发者工具都能读到。
它是为镜头、投影仪和你旁边那个人准备的，不是为了防住一个已经能操作你电脑的人。

遮挡也只作用于文件列表：标签页标题、笔记自己的面包屑、搜索结果和快速切换器都不受
影响，想按名字搜索，先把遮挡关掉。另外，如果你关掉「收起其他所有文件夹」，骨架条
仍然会露出每个文件夹里有多少个文件、树有多深。

## 安装

在 Obsidian 里打开 设置 → 第三方插件 → 浏览，搜索 **Immersive Folder** 安装即可，
也可以直接打开[社区插件页面](https://community.obsidian.md/plugins/immersive-folder)。

需要 **Obsidian 1.13 或更高版本**。移动端各项功能同样正常，可以放心使用。

也可以手动安装：从[最新
release](https://github.com/iBlinkQ/immersive-folder/releases/latest) 下载
`main.js`、`manifest.json` 和 `styles.css`，放进
`你的库/.obsidian/plugins/immersive-folder/`，然后在 设置 → 第三方插件 里启用。
（`main.js` 是构建产物，不保存在仓库里 —— 它只存在于 release 中，或者你自己跑
`npm run build` 之后。）

有问题或建议，欢迎提
[Issue](https://github.com/iBlinkQ/immersive-folder/issues)。

## 开发

```bash
npm install
npm run dev     # 监听构建
npm run build   # 类型检查并构建 main.js
npm run lint    # 社区插件审核所用的那套规则
npm run sync    # 构建后复制进 sync.mjs 里列出的库
```

`npm run lint` 必须在仓库根目录跑：规则会从工作目录读 `manifest.json`。
