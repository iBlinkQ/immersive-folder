# Immersive Folder

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · 日本語 · [한국어](README.ko.md)

Obsidian のプラグインです。あるフォルダーで作業しているあいだ、ワンクリックで
ファイルエクスプローラーをそのフォルダーのノートだけに絞り込み、それ以外は
いったん覆い隠します。フォルダーはドラッグで好きな順に並べ替えられるので、
順番をそろえるために `01_Inbox`、`02_Projects` のような名前を付ける必要も
なくなります。

![Clippings フォルダーだけが読め、ほかの行はすべてスケルトンバーになったファイルエクスプローラー](docs/screenshot.png)

どのフォルダーに没入するかは、開いているファイルから自動的に決まります。選ぶ操作は
ありません。

## なぜ必要か

- **集中。** 2000 件のノートを抱えた保管庫が、いま実際に手を動かしている十数件と
  注意を奪い合わなくなります。
- **会議での投影。** プロジェクターに映してひとつのプロジェクトを説明するとき、
  部屋の全員が読むのはそのプロジェクトだけです。隣のプロジェクトや別の顧客、
  自分用に置いてあるものの名前が目に入ることはありません。
- **画面録画。** 動画で扱うフォルダーだけを見せ、サイドバーの残りは読めないままに
  できます。撮る前に保管庫を整理し直す必要はありません。

## 使い方

- **ファイルエクスプローラー上部のボタン**で切り替えます。覆いが出ているあいだは
  アクセントカラーを帯びるので、状態がひと目で分かります。
- コマンドパレットの **`Immersive Folder: Toggle immersive folder`** も同じ働きを
  します。ホットキーを割り当てられるので、録画のたびに切り替えるなら便利です。

状態は再起動をまたいで保持されます。

### フォルダーの順序を変える

ファイルエクスプローラー上部の上下矢印ボタンを押すと、すべてのフォルダーが少し
浮き上がり、それぞれの先頭にハンドルが現れます。あとはドラッグして順序を決める
だけです。変更はその都度保存され、もう一度ボタンを押すと抜けられます。

![フォルダー並べ替えモードで、フォルダーをドラッグすると同じ階層の中での位置が変わる](docs/arrange.gif)

並べ替えられるのは同じ階層のあいだだけです。フォルダーは自分がいるフォルダーの中で
動き、別の階層へ引き出すことはできません。これで順序の変更と場所の移動が混ざらずに
済みます。

参加するのはフォルダーだけです。ファイルの順序はこれまでどおり Obsidian が決めるので、
並べ替えメニューで名前順にしていても更新日順にしていても、そのまま働きます。

これはこのプラグイン独自のモードで、ここでやることはフォルダーの順序を決めること
だけです。モードを抜ければ Obsidian 本来のドラッグがそのまま使え、ファイルや
フォルダーを別の場所へ移す操作も今までどおりです。2 つの機能は互いに干渉しません。

プラグインが記録するのは順序だけです。名前を変えることも、ファイルを移動することも
なく、保管庫にそれ以外を書き込むこともありません。

### 設定

**Language（言語）** —— インターフェースは Obsidian 自体の言語設定に従います。
プラグインに同梱されているのは英語と简体中文で、ここで選べばその判定を上書き
できます。コマンド名も含め、その場で切り替わります。

**Toolbar buttons（ツールバーボタン）** —— このプラグインの 2 つのボタンのうち、
どれをファイルエクスプローラーの上部に置くか。どちらもモードのオン・オフが見える
スイッチなので、既定では両方とも見える場所にあります。片方の機能しか使わないなら
もう一方は隠せます。隠したものもコマンドパレットからは使え、何かを隠すと設定
ページからホットキー設定へ直接移動できる行が現れます。

**Keep the active file in view（アクティブなファイルを表示範囲に保つ）** ——
ノートを切り替えるたびにエクスプローラーをそのノートまでスクロールし、必要な階層を
展開して見えるようにします。これがないと、フォルダーが表示範囲外にあるノートへ
切り替えたとき、画面にはバーだけが残ります。既定でオンです。

**Collapse every other folder（ほかのフォルダーをすべて折りたたむ）** ——
切り替えのたびに、いるフォルダー以外をすべて折りたたみます。スクロールする量が
減り、ほかのフォルダーが何件抱えているかをバーが漏らすこともなくなります。開いて
いたものは没入モードを抜けるときに元に戻ります。既定でオンです。

## できないこと

**これは視覚的な覆いであって、暗号化ではありません。** 名前はページの中に残って
いるので、開発者ツールを開ける人には読めます。カメラやプロジェクター、隣の席の人を
想定したものであって、すでにあなたのマシンを操作できる相手を想定したものでは
ありません。

覆いがかかるのはファイルエクスプローラーだけです。タブのタイトル、ノート自身の
パンくず、検索結果、クイックスイッチャーはそのままなので、名前で検索したいときは
覆いを外してください。また **Collapse every other folder** をオフにすると、各
フォルダーが何件抱えているか、ツリーがどれだけ深いかはバーから伝わります。

## インストール

Obsidian で 設定 → コミュニティプラグイン → 閲覧 を開き、**Immersive Folder** を
検索してインストールしてください。[プラグインページ](https://community.obsidian.md/plugins/immersive-folder)
から直接開くこともできます。

**Obsidian 1.13 以降**が必要です。モバイルでもすべての機能がそのまま使えます。

手動で入れる場合は、[最新の
release](https://github.com/iBlinkQ/immersive-folder/releases/latest) から
`main.js`、`manifest.json`、`styles.css` をダウンロードし、
`あなたの保管庫/.obsidian/plugins/immersive-folder/` に置いて、設定 →
コミュニティプラグイン から有効にしてください。（`main.js` はビルド成果物で
リポジトリには入っていません。リリースの中か、自分で `npm run build` を実行した
あとにだけ存在します。）

質問や提案は [Issues](https://github.com/iBlinkQ/immersive-folder/issues) へ
どうぞ。

## 開発

```bash
npm install
npm run dev     # ウォッチビルド
npm run build   # 型チェックして main.js をビルド
npm run lint    # コミュニティプラグイン審査が走らせるルール
npm run sync    # ビルドして sync.mjs に列挙した保管庫へコピー
```

`npm run lint` はリポジトリのルートで実行する必要があります。ルールが作業ディレクトリ
から `manifest.json` を読むためです。
