# Immersive Folder

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · 한국어

Obsidian 플러그인입니다. 어떤 폴더에서 작업하는 동안, 클릭 한 번으로 파일 탐색기를
그 폴더의 노트만 남게 좁히고 나머지는 잠시 가려 둡니다. 폴더는 원하는 순서대로
끌어다 놓을 수 있어서, 순서를 맞추자고 `01_Inbox`, `02_Projects` 같은 이름을 붙일
필요도 없어집니다.

![Clippings 폴더만 읽히고 나머지 줄은 모두 스켈레톤 막대가 된 파일 탐색기](docs/screenshot.png)

어느 폴더에 몰입할지는 열어 둔 파일을 보고 자동으로 정해집니다. 따로 고를 것은
없습니다.

## 왜 필요한가

- **집중.** 노트 2000편짜리 보관소가, 지금 실제로 손대고 있는 열몇 편과 주의를
  두고 다투지 않게 됩니다.
- **회의 화면 공유.** 프로젝터에 띄워 놓고 한 프로젝트를 설명할 때, 사람들이 읽는
  것은 그 프로젝트뿐입니다. 옆 프로젝트나 다른 고객, 혼자 보려고 둔 것들의 이름이
  눈에 들어오지 않습니다.
- **화면 녹화.** 영상에서 다룰 폴더만 보여 주고 사이드바의 나머지는 읽히지 않게
  둘 수 있습니다. 찍기 전에 보관소를 정리할 필요가 없습니다.

## 사용법

- **파일 탐색기 위쪽 버튼**으로 켜고 끕니다. 가림막이 올라가 있는 동안에는 강조
  색을 띠어서 상태가 한눈에 보입니다.
- 명령 팔레트의 **`Immersive Folder: Toggle immersive folder`** 도 같은 일을
  합니다. 단축키를 지정할 수 있으니 녹화할 때마다 켜고 끈다면 하나 지정해 두는
  편이 낫습니다.

켜고 끈 상태는 다시 시작해도 그대로 유지됩니다.

### 폴더 순서 바꾸기

파일 탐색기 위쪽의 위아래 화살표 버튼을 누르면 모든 폴더가 살짝 떠오르고 각 폴더
앞에 손잡이가 생깁니다. 이제 폴더를 끌어서 순서를 정하면 됩니다. 바뀐 순서는 그때
그때 저장되고, 버튼을 다시 누르면 빠져나옵니다.

![폴더 배열 모드에서 폴더를 끌면 같은 층 폴더들 사이에서 자리가 바뀐다](docs/arrange.gif)

순서는 같은 층 안에서만 바꿀 수 있습니다. 폴더는 자기가 속한 폴더 안에서만 움직이고
다른 층으로 끌어낼 수는 없습니다. 이렇게 해야 순서 바꾸기와 자리 옮기기가 섞이지
않습니다.

순서 바꾸기에 참여하는 것은 폴더뿐입니다. 파일 순서는 여전히 Obsidian이 정하므로,
정렬 메뉴에서 이름순을 골랐든 날짜순을 골랐든 하던 대로 작동합니다.

이것은 이 플러그인만의 모드이고, 그 안에서 하는 일은 폴더 순서를 정하는 것 하나
입니다. 모드를 빠져나오면 Obsidian 본래의 드래그가 그대로 동작해서, 파일이나 폴더를
다른 자리로 옮기는 것도 전과 같습니다. 두 기능은 서로 간섭하지 않습니다.

플러그인이 기록하는 것은 순서뿐입니다. 이름을 바꾸지도, 파일을 옮기지도 않고,
보관소에 그 밖의 것을 쓰지도 않습니다.

### 설정

**Language(언어)** —— 인터페이스는 Obsidian 자체의 언어 설정을 따릅니다. 플러그인에
들어 있는 것은 영어와 简体中文이며, 여기서 하나를 골라 자동 판정을 덮어쓸 수
있습니다. 명령 이름까지 그 자리에서 바뀝니다.

**Toolbar buttons(도구 모음 버튼)** —— 이 플러그인의 버튼 두 개 중 무엇을 파일
탐색기 위쪽에 둘지 정합니다. 둘 다 모드가 켜졌는지 보이는 스위치라 기본적으로는
둘 다 눈에 띄는 자리에 있습니다. 한쪽 기능만 쓴다면 다른 쪽은 숨겨도 됩니다.
숨긴 것도 명령 팔레트에서는 그대로 쓸 수 있고, 무언가를 숨기면 설정 페이지에서
단축키 페이지로 바로 갈 수 있는 줄이 하나 생깁니다.

**Keep the active file in view(현재 파일을 보이는 곳에 두기)** —— 노트를 옮길
때마다 탐색기를 그 노트까지 스크롤하고, 보이게 하는 데 필요한 만큼 펼칩니다. 이것이
없으면 폴더가 화면 밖에 있는 노트로 옮겼을 때 온통 막대뿐인 화면만 보게 됩니다.
기본으로 켜져 있습니다.

**Collapse every other folder(다른 폴더 모두 접기)** —— 옮길 때마다 지금 있는
폴더를 뺀 모든 폴더를 접습니다. 스크롤할 것이 줄고, 다른 폴더가 파일을 몇 개나
품고 있는지 막대가 흘리는 일도 없어집니다. 펼쳐져 있던 것은 몰입 모드를 빠져나올
때 되돌려 놓습니다. 기본으로 켜져 있습니다.

## 하지 못하는 일

**이것은 시각적인 가림막이지 암호화가 아닙니다.** 이름은 여전히 페이지 안에 남아
있어서 개발자 도구를 열 수 있는 사람은 읽을 수 있습니다. 카메라와 프로젝터, 옆자리
사람을 염두에 둔 것이지, 이미 당신의 기기를 만질 수 있는 상대를 막으려고 만든 것은
아닙니다.

가림막이 적용되는 곳은 파일 탐색기뿐입니다. 탭 제목, 노트 자체의 경로 표시, 검색
결과, 빠른 전환기는 그대로이니 이름으로 검색하려면 가림막을 끄면 됩니다. 그리고
**Collapse every other folder** 를 꺼 두면 각 폴더가 파일을 몇 개나 품고 있는지,
트리가 얼마나 깊은지는 막대만으로도 드러납니다.

## 설치

Obsidian에서 설정 → 커뮤니티 플러그인 → 둘러보기를 열고 **Immersive Folder** 를
검색해 설치하면 됩니다. [플러그인 페이지](https://community.obsidian.md/plugins/immersive-folder)로
바로 가도 됩니다.

**Obsidian 1.13 이상**이 필요합니다. 모바일에서도 모든 기능이 그대로 동작합니다.

직접 설치하려면 [최신
release](https://github.com/iBlinkQ/immersive-folder/releases/latest)에서
`main.js`, `manifest.json`, `styles.css`를 내려받아
`당신의보관소/.obsidian/plugins/immersive-folder/`에 넣고, 설정 → 커뮤니티
플러그인에서 켜면 됩니다. (`main.js`는 빌드 산출물이라 저장소에는 없습니다.
릴리스 안에, 또는 직접 `npm run build`를 실행한 뒤에만 존재합니다.)

궁금한 점이나 제안은 [Issues](https://github.com/iBlinkQ/immersive-folder/issues)로
남겨 주세요.

## 개발

```bash
npm install
npm run dev     # 감시 빌드
npm run build   # 타입 검사 후 main.js 빌드
npm run lint    # 커뮤니티 플러그인 심사가 돌리는 규칙
npm run sync    # 빌드한 뒤 sync.mjs에 적힌 보관소로 복사
```

`npm run lint`는 저장소 루트에서 실행해야 합니다. 규칙이 작업 디렉터리에서
`manifest.json`을 읽기 때문입니다.
